# chandramohan21.github.io

Personal website of Chandramohan K. The page is in `index.html`.

The layout is an academic single page: bio and links beside the profile photo (`images/profile.webp`; `images/profile.jpg` is the link-preview copy), then Research, Projects, Experience, Education and Contact. Everything is plain HTML, so to add a study, project or job, open `index.html`, copy one `<article class="entry">` (research and projects) or `<li class="cv-item">` (experience and education) block, and edit the text. Images go in `images/`.
